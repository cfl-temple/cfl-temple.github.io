## Open Source Projects

### TGDH - python
**Description:** TGDH is a shared cryptographic key established among all members of a dynamic group using the Tree-based Group Diffie–Hellman (TGDH) protocol. It enables secure group communication by allowing members to efficiently compute a common secret while supporting dynamic membership changes (join/leave) with scalable rekeying and forward/backward secrecy.

**Technologies:** Python

**GitHub:** [Repository Link](https://github.com/lbaitemple/tgdhstruct){:target="_blank"}

---

### Tennessee Eastman Model
**Description:** This MATLAB code implements a dynamic simulation of the Tennessee Eastman (TE) process, a benchmark industrial chemical process widely used for research in process control, monitoring, and fault diagnosis. The simulation models the plant’s nonlinear dynamics, operating conditions, and disturbances, enabling evaluation of control strategies, state estimation, and fault detection algorithms.

**Technologies:** Matlab, Java

**GitHub:** [Repository Link](https://github.com/lbaitemple/TED){:target="_blank"}

## Web Applications

### Virtual Power Laboratory (VPL)
**Description:** A web-based virtual laboratory for electric machines courses. Students work through nine experiments on DC generators and motors, from the magnetization characteristics of a separately excited machine to the speed–torque characteristics of a series motor, with learning material and a student manual. Instructors can manage students, track scores and run a full lab course through the built-in grade center. Supported by the National Science Foundation.

**Technologies:** HTML, JavaScript (jQuery, Bootstrap), Google Apps Script, Adobe Captivate

**Credits:** [Dr. Saroj Biswas](https://engineering.temple.edu/directory/saroj-biswas){:target="_blank"}, [Dr. Li Bai]({{ site.baseurl }}/team/bai-li), [Ning Gong]({{ site.baseurl }}/team/ning-gong)

**Website:** [Open VPL](https://lbaitemple.github.io/templepowerlab/){:target="_blank"}
